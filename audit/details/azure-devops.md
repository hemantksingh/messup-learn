## Cross-file observations

1. **Time-critical item.** Azure Functions.md teaches the .NET in-process model (`--worker-runtime dotnet`, .NET Core 2.2). Microsoft ends support for the in-process model on 10 Nov 2026, eight weeks after this audit. Any agent using this note as a reference would generate an unsupported project. This is the single most urgent rewrite in the set.

2. **Entra ID rename spans four files.** "Azure AD"/"Azure Active Directory" appears in Azure Cli.md, Azure/Overview.md, Terraform.md (provider description) and every label in AzureAd.drawio plus its exported PNGs. Fix once with a consistent convention: "Microsoft Entra ID (formerly Azure AD)" on first use per file; keep literal tool names (`az ad`, `azuread` provider) unchanged and say so, otherwise an agent will "correct" valid command names.

3. **Azure CLI 2.37 (May 2022) broke most `az ad` snippets** in Azure Cli.md. The file was last touched 2022-03-30, six weeks before the breaking release. Every `az ad app create`, `az ad app credential reset` and `az ad app permission grant` example (verified 2.37 breaking changes) and every `az ad sp create-for-rbac` example (no default role on current CLI) needs re-testing against a current CLI.

4. **Classic administrator roles.** Azure/Overview.md and AzureAd.drawio both build the subscription-transfer explanation on "Service Admin", retired 31 Aug 2024. Rewrite in terms of RBAC Owner + billing account roles.

5. **No ARM-templates-vs-Bicep coverage anywhere in the repo.** Terraform.md has an "Arm and Terraform" heading with one sentence about Cloud Shell, and DevOps/Overview.md lists only Terraform and CloudFormation as provisioning tools. Word-boundary grep for `bicep`, `entra`, `opentofu` returns nothing. For an Azure-heavy knowledge base this is a gap; the natural home is a new `Azure/Infrastructure as Code.md` (ARM JSON vs Bicep vs Terraform/azurerm vs azapi), linked from Terraform.md.

6. **Terraform licence/fork not reflected.** Terraform.md predates BSL by six weeks and still calls Terraform "open source"; OpenTofu and HCP Terraform (renamed Apr 2024) are absent. Terragrunt now defaults to OpenTofu, which also dates the Terragrunt section.

7. **Duplicate/orphan Ansible pages.** `DevOps/Ansible.md` (7 lines, conceptual) and `Cheat sheets/Ansible.md` (practical, H1 "Installation") cover one tool across two top-level folders with no cross-link. Merge into one page with a proper `# Ansible` H1.

8. **DevOps folder mixes four categories:** practice/methodology (Overview.md, SRE.md), configuration management (Ansible.md, Chef.md), infrastructure as code (Terraform.md) and a vendor CI/CD product (Azure DevOps.md). An agent asked "what CI/CD tools are documented" or "what IaC tools" gets no structural signal. Suggested layout: `DevOps/Practices/` (DevOps, SRE, CI-CD Principles), `DevOps/Configuration Management/` (Ansible, Chef, with Puppet mentioned only in Overview), `DevOps/Infrastructure as Code/` (Terraform, plus new ARM/Bicep page), and move Azure DevOps.md under `Azure/` or `DevOps/CI-CD/`.

9. **SRE/SLO content is split three ways:** SRE.md (fragments), DevOps/Overview.md L3-5 (SRE vs DevOps), Distributed Systems/Monitoring and Observability.md L191-269 (SLIs/SLOs/error budgets in practice). Consolidate the definitions in one place and link.

10. **Repo-wide RTO definition error.** DevOps/Overview.md L28 and AWS/DR and Business Continuity.md L10 both define RTO as an elapsed/measured time rather than an objective. They agree with each other, so this is a shared WRONG rather than an INCONSISTENT, and should be fixed in both.

11. **Unattributed verbatim passages** (Google SRE book in DevOps/Overview.md L47 and SRE.md L20; Octopus Deploy docs in DevOps/Overview.md L94-109; an unnamed Terraform article in Terraform.md L3-10 including "this article"). For a KB that agents will quote, attribution matters both for provenance and because some of this text is vendor opinion.

12. **`Overview.md` naming convention.** Azure, AWS, Kubernetes and DevOps folders all use `Overview.md` with an H1 of the folder topic. Acceptable, but decide once and document it (e.g. in README) so the H1/filename mismatch is intentional rather than flagged repeatedly.

13. **Employer-specific identifiers** (`kalibrate`, `kalibratepricing`, `beta-abc-us`) and a personal Azure DevOps org URL (`dev.azure.com/hemantk`) are embedded in snippets. Replace with placeholders before the notes are used as a shared reference.

14. **Diagram source file is invisible.** AzureAd.drawio is referenced nowhere; the three PNGs it produced are referenced only by filename-as-alt-text. Add a "source: AzureAd.drawio" note or adopt a `Images/src/` convention so agents (and humans) can regenerate diagrams after the Entra rename.

15. **Code fence hygiene.** Terraform.md tags six HCL blocks as `sh`; Azure Functions.md mixes PowerShell assignment into an `sh` block; Security.md wraps prose in `sh`. An agent extracting runnable snippets by fence language would execute the wrong thing.
