## Cross-file observations

1. **Index and naming.** `Security.md` is the only file that links siblings (IAM, KMS, Networking) and therefore acts as the folder index, while `Overview.md` (H1 "AWS") is an EC2 tutorial. An agent will open `Overview.md` expecting the entry point. Recommend: rename `Overview.md` -> `EC2 and EBS.md`, and either turn `Security.md`'s top into a full folder index or add a genuine `Overview.md` that links all nine notes.
2. **H1 / filename mismatches** in four of nine notes: `Overview.md` ("AWS"), `Security - Networking.md` ("Networking"), `EventBridge_SQS_SNS.md` ("Asynchronous messaging"), `Security.md` ("AWS Security" - acceptable). `EventBridge_SQS_SNS.md` is also the only underscore-named file in the folder.
3. **Namespace collision with top-level `Networking/`.** "Networking" H1 in the AWS folder vs `Networking/DNS.md`, `IPRouting.md`, `Network Layers.md`. Retitle to "AWS VPC Networking" so retrieval does not conflate OSI-layer notes with VPC notes.
4. **Terminology drift across files.** KMS.md uses both "KMS key" and the retired "CMK"; IAM.md says "AWS Cloud Trail", Security.md "AWS CloudTrail"; Security.md spells "Analyser" in a heading and "Analyzer" in the body; EKS.md uses "EKS Node Managed" for "managed node groups". Standardise on current AWS product names.
5. **Security tooling duplication.** `Security.md` L39/L112 re-describes Prowler, ScoutSuite and Security Monkey which `Security/Cloud Security.md` already tabulates (with a Prowler-vs-ScoutSuite comparison). Link rather than duplicate.
6. **Inconsistent troubleshooting guidance.** `Overview.md` L33 says browser access needs SG + subnet route + NACL; `Security - Networking.md` L46 attributes timeouts to route table/NACL only. Align (SG is the most common cause).
7. **Already-false-at-commit items** (worth calling out because the commit dates are recent): IAM.md L17 DynamoDB has no resource policies (false since 2024-03-20, committed 2024-06-17); KMS.md omits XKS (GA 2022, committed 2024-03); Security.md describes Inspector Classic (superseded 2021, committed 2024-03); Networking.md Direct Connect speeds (100 Gbps since 2021, committed 2025-08); EKS.md /16 claim (secondary CIDRs since 2017, committed 2021).
8. **Highest-impact corrections for an agent-facing KB** (things an agent would confidently repeat and be wrong): SG statefulness (Networking L39), KMS deletion "instantaneous" (KMS L33), EventBridge Pipes description (Messaging L37), SNS "message is lost" (Messaging L20/L27), `public-ip4` + IMDSv1 curl (Overview L43-49), invalid JSON policies (IAM L53-83), ARN format (IAM L47), EKS /16 networking (EKS L26-28).
9. **Gaps an agent will be asked about but the folder never covers:** Lambda limits/quotas, S3 fundamentals, RDS/Aurora, CloudFormation/CDK/Terraform on AWS, Organizations/SCPs, cost basics, regions/AZs model. Nothing here is wrong, but the folder's coverage is skewed to security + a few point topics, so tags should not imply "AWS reference".
10. **Diagram source.** `AWS.drawio` is orphaned; the "Serverless DR" page depicts the DR note's multi-region section, which currently has no image. Export it and reference the `.drawio` from the three notes whose PNGs it generated (IAM federation, security patterns).
11. **Suggested renames/merges within the set:** `Overview.md` -> `EC2 and EBS.md`; `Security - Networking.md` -> `VPC Networking.md` (H1 "AWS VPC Networking"); `EventBridge_SQS_SNS.md` -> `Messaging - EventBridge, SQS, SNS.md`; `AWS Cli.md` -> `Cheat sheets/AWS CLI.md`; `DR and Business Continuity.md` -> keep name but split generic DR/RTO/RPO section into a top-level note if a generic resilience note is wanted; `EKS.md` -> full rewrite or archive with a "superseded" banner.
