- `CICD.md` → `Cloud and Infrastructure/DevOps/` next to `Azure DevOps.md` (which already documents Azure Pipelines stages/jobs/tasks — the real overlap). `Distributed Systems/Continuous Deployment.md` was checked: it is a short note on separating deployment from release via feature flags; it shares only the "CD" name with CICD.md and there is no duplicate content between them.

- `Tesseract.md` → fold into `Data and AI/Machine Learning.md` or delete.
